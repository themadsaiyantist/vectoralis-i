# Brief

The first step of a heavy session. The session start already printed the briefing. This turns it into a goal.

1. Read `## Now` in `harness/todo.md`. It is the handoff from the last session.
2. Read the first open box under `## The agent's`, and the tracker rows of the area it touches.
3. Read the open entries of `harness/failures.md`. An open failure is fixed before new work starts, unless the person says otherwise.
4. Read the stale line of the briefing. A stale record is fixed first, because it is cheaper now than later. `vectoralis check` prints the full list.
5. Say the session's goal in one or two lines: the box you will close, and how you will know it is closed.
6. If the goal needs a call that is the person's, go to the `plan` skill and ask before the first edit.
