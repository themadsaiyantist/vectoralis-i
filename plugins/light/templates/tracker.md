# Tracker

The build state. ✅ is done and checked, ⬜ is not done, a blank cell does not apply. Nothing else goes in a cell. The last column is the person's. A unit that opens with a path in backticks is bound to that file: when the file changes after the tick, `vectoralis check` flags the row until it is checked again.
