# The Topics

Five topics that sit outside the three roadmaps, and that people are building on right now. Each page gives you what it is, why now, the first steps as boxes, ranked resources, and something to build. Read the one that pulls you.

**Contents:** The five · How to read a topic · See also

---

## The five

| The topic | What it is | Read it when |
|---|---|---|
| [Local and open models](local-models.md) | running and tuning a model on your own machine | you want an agent that works with the network off, or code that never leaves the room |
| [Voice and real-time agents](voice-agents.md) | speech in, speech out, and the turn-taking between them | you want something a person can talk to |
| [Computer use and browser agents](computer-use.md) | a model that drives a screen or a browser | the thing you need has no API |
| [AI security](ai-security.md) | injected instructions, permissions, secrets, the supply chain of skills and servers | you are about to give an agent real access |
| [Generative media](generative-media.md) | image and video pipelines a developer can script | you want pictures and video from code |

## How to read a topic

- **Start here** is a list of boxes, from nothing to a working thing.
- **The stars are a judgment**, from 1 to 10, made on the date at the bottom of the page.
- **Free comes first.** A paid resource appears only when it is greatly better, with its price.
- **Build this** names a public repository to study for each idea.
- **The kit** line points at the [kit](../kit/README.md) pages that serve the topic.
